# Secure Password Manager

A modern and secure Password Manager Web Application built using Flask, MySQL, HTML, CSS, and JavaScript.

This project allows users to securely save and manage passwords with encryption support and a clean responsive UI.

---

## Features

- Save Passwords Securely
- Password Encryption using Fernet
- Show / Hide Password Functionality
- Delete Saved Passwords
- MySQL Database Integration
- Responsive Modern UI
- Flask Backend Routing
- Dynamic Password Rendering

---

## Technologies Used

- Python
- Flask
- MySQL
- PyMySQL

- CSS3
- JavaScript
- Cryptography (Fernet Encryption)
